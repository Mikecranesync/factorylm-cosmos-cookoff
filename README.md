# FactoryLM: NVIDIA Cosmos Cookoff entry (archived)

This repository is an archived prototype built for the NVIDIA Cosmos Cookoff hackathon in early 2026. It is not a product and is not maintained.

It is not a safety system. Nothing here is designed, tested or certified to protect people, loads or equipment, and none of it should be used to monitor or control a crane, hoist or any other machine.

For the current product, MIRA by FactoryLM, see [factorylm.com](https://factorylm.com).
